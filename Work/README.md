# Work and industrial/OT scripts

Generic, sanitized utilities related to industrial systems, operational technology, networking, and automation.

Suggested categories:

- `Industrial/` — vendor-neutral industrial automation helpers
- `Network/` — diagnostics and validation suitable for controlled environments
- `OT/` — operational technology monitoring and maintenance helpers
- `Utilities/` — generic supporting tools

Only publish material you are authorized to share. Do not commit customer or employer information, real asset names, private hostnames or IP addresses, credentials, certificates, configuration exports, logs, network captures, or proprietary procedures.

Treat every script as untrusted until it has been independently reviewed and tested for the target environment. Follow applicable safety, cybersecurity, change-control, and recovery procedures.
