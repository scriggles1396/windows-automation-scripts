# Personal scripts

Convenience scripts for everyday tasks and personal systems.

Suggested categories:

- `Media/` — download, conversion, metadata, and library helpers
- `Network/` — connectivity checks and home-network diagnostics
- `System/` — Windows setup, maintenance, and configuration
- `Utilities/` — general-purpose helpers that do not fit another category

Each script should include the repository's reusable header, usage examples, requirements, and any important side effects. Never commit personal credentials, private service URLs, tokens, or other sensitive information.
